- contact.html
- styles.css
- script.js
- logo.svg

How to use:
1. Download and unzip.
2. Replace the placeholder phone number (01865 000000) and email if needed.
3. Replace the placeholder images with your photos (in images/), adjust content.
4. Upload files to a GitHub repository and enable GitHub Pages (Settings -> Pages -> Deploy from branch -> main / root).

Contact form currently uses mailto fallback. For production, integrate with a form service (Netlify Forms, Formspree, or your own backend).
